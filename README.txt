# Sona & Rahul — Royal E-Invitation

## Included
- Royal responsive invitation website
- Engagement, wedding and reception sections
- Countdown to the wedding
- Couple photo
- Google Maps buttons
- Family section
- Music control
- Mobile-friendly design

## Files
- index.html
- style.css
- script.js
- assets/couple.jpg
- assets/aaha-kalyanam.mp3 (add your legally obtained audio file)

## Add the music
Place your own copy of the song as:

assets/aaha-kalyanam.mp3

The browser will not reliably autoplay music without a user interaction, so the invitation has an "Open Invitation" button and a floating music button.

## Run
Open index.html in a browser, or use VS Code + Live Server.
